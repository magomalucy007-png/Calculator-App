# Scientific Calculator App

A modern Java Swing calculator with a scientific mode built for everyday math and advanced expressions.

## Features

- Basic arithmetic: +, -, *, /
- Parentheses and exponentiation
- Scientific functions: sin, cos, tan, sqrt, log, ln
- Constants: π and e
- Memory-style Ans support for chaining calculations
- Clear and backspace controls
- Clean desktop-style interface

## Requirements

- Java 8 or newer
- No external libraries required

## How to Run

1. Compile the app:
   ```bash
   javac Calculator.java
   ```

2. Run the app:
   ```bash
   java Calculator
   ```

## Usage

- Click the buttons to build expressions
- Use = to evaluate the expression
- Use C to clear the screen
- Use Ans to reuse the previous result
- Try expressions such as `sin(30)`, `sqrt(16)`, `2^8`, or `pi*2`

## Project Files

- Calculator.java: main application source code

## Notes

The calculator uses a built-in expression parser so it works without relying on deprecated Java scripting APIs.
